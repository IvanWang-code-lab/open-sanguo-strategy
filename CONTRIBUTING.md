# Contributing

Thank you for your interest in contributing to Open Sanguo Strategy.

This project is currently in early development. Contributions are welcome in the following areas:

- Bug reports
- Documentation improvements
- Gameplay system design
- Refactoring suggestions
- TypeScript and React improvements
- Scenario and data structure proposals

## Development Principles

- Keep changes small and reviewable
- Avoid large rewrites without discussion
- Prefer clear, maintainable code
- Add explanations for gameplay logic
- Keep the project beginner-friendly

## How to Contribute

1. Open an issue describing the problem or idea.
2. Fork the repository.
3. Create a feature branch.
4. Submit a pull request with a clear description.

## Code Style

- Use TypeScript where possible
- Keep naming clear and consistent
- Avoid unnecessary dependencies
- Prefer readable logic over clever shortcuts
