# Security Policy

Open Sanguo Strategy is a browser-based open-source strategy game framework.

## Reporting Security Issues

If you discover a security issue, please open a private security advisory or contact the maintainer directly.

Please do not publicly disclose security vulnerabilities before they have been reviewed.

## Scope

Security issues may include:

- Dependency vulnerabilities
- Unsafe user-generated content handling
- Build or development workflow risks
- Client-side data handling issues

## Notes

This project is currently in early development. Security review and dependency hygiene will improve as the codebase matures.
