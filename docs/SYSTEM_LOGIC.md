# 系统逻辑说明

## 项目定位

《三国：新霸王大陆》是本地单机网页策略游戏，目标是在无后端、无数据库、无外部资源依赖的前提下提供稳定可玩的三国战略体验。V10.5 在人物真实性设定包和 V10.4 指令系统基础上，进一步强化命令菜单、军团编成 2.0、五阶段战术指挥和战后复盘。核心体验是选择主公、分配本回合有限指令、经营城池、搜索群英、战前军议、微调军团、阶段式指挥战斗并统一天下。

## 人物设定来源优先级

本游戏的人物设定采用“史实骨架 + 演义人格 + 游戏化可玩性”的混合体系。

第一层是三国基础史实骨架，用于确定人物是否存在、所属势力、大致时代、主要职能、主要事迹和阵营关系。

第二层是大众认知人格，主要来自《三国演义》和长期形成的三国文化印象，用于确定忠义、枭雄、仁德、神机妙算、狂勇、门阀贵胄等性格标签和戏剧气质。

第三层是游戏化可玩性，用于确定五维属性、技能设计、战斗定位、内政定位、稀有度、强度差异和爽感表现。人物资料不足时，按基础三国认知、阵营定位和游戏性补全。

视觉表达遵循“原创但认知对味”：不复制任何现成游戏、影视或动画官方立绘，而是用视觉关键词、服饰方向、色彩和角色标签让玩家自然识别人物气质。

## 游戏流程

游戏从主公选择界面开始。玩家选择势力后创建 190 年 1 月剧本，进入战略地图。每回合玩家拥有有限政令和军令，城市行动后仍会标记为已行动，但能否行动首先受全局指令预算限制。玩家可用政令发展、修城、搜索、安抚，用军令征兵、训练、侦察、出征。出征会先进入战前军议，确认军团编成和战斗操控模式后进入战斗。点击结束回合后，系统推进时间、结算资源、随机天气、检查武将登场、执行 AI、重置城市行动、刷新玩家指令并自动保存。

## 主公选择逻辑

势力数据定义在 `src/data/factions.ts`。启动时先读取 localStorage 存档；如果没有有效存档，则显示 `LordSelect`。玩家点击势力卡片后只记录选择，不会默认刘备。点击开始游戏后，`scenarioSystem.createInitialGame` 根据选择设置 `playerFactionId` 和势力 `isPlayer`。V0.1.1 起，重新选择主公会同时清空游戏存档和上次势力选择，确保重新开局必须再次明确选择。V0.3.1 起，主公选择页使用 `ART_ASSETS.backgrounds.lordSelect` 作为背景，并通过 `getFactionPortrait(faction.id)` 显示势力头像。V10.2 起，主公卡片额外显示核心主公的设定标签、角色定位和评语。

## 城市系统逻辑

城市数据定义在 `src/data/cities.ts`，包含 id、名称、坐标、所属势力、地形、兵种、资源、农业、商业、城防、士气、民心、行动状态和驻守武将。地图路线在 `src/data/routes.ts`，只有路线相连的城市可以互相出征。城市颜色由所属势力颜色决定，己方、敌方和在野/空城在地图上有不同视觉表现。V0.3.1 起，`MapView` 使用 `ART_ASSETS.backgrounds.mapClean` 作为 SVG 底图，原 x/y 坐标继续负责节点定位。

## 指令系统逻辑

V10.5 的指令系统 2.0 由 `src/systems/commandSystem.ts` 维护。玩家每回合拥有政令和军令。政令用于发展农业、发展商业、修筑城防、搜索武将、安抚民心；军令用于征兵、训练士兵、侦察敌情和出征。指令每回合刷新，本版不累积未使用指令。

政令计算：基础 2，每 2 座城市 +1；主公政治达到 85 或拥有治理/声望类技能可额外增加。军令计算：基础 1，每 3 座城市 +1；主公统率达到 85 或拥有统御、江东等军事风格技能可增加。城市越多指令越多，但当城市数超过 8 且平均民心低于 50、或城市数超过 12 且平均民心低于 45 时，会产生统治负担并减少政令。主公高政治、仁德、安民等能力可抵消部分负担；暴政风格在低民心时更容易产生额外压力。

`CommandState` 记录当前政令、最大政令、当前军令、最大军令、指令效率、统治负担、平均民心、来源拆解、已用指令、剩余可操作城市和顾问建议。旧存档没有该字段时，读档会自动补齐。顶部栏以令牌式 UI 显示政令/军令，悬停显示基础值、城市加成、主公加成、势力加成、统治负担和最终值。

## 兵种系统逻辑

兵种结构为 `troops: { infantry, cavalry, archer, navy }`。`unitSystem.ts` 提供总兵力、兵力缩放、兵种战力和克制系数计算。骑兵克制步兵、步兵克制弓兵、弓兵克制骑兵，克制以双方兵种占比差计算，避免单一兵种造成极端结果。

## 地形系统逻辑

城市地形包括平原、山地、江河、林地和城池。战斗中平原提高骑兵战力，山地提高步兵并削弱骑兵，江河提高水军并削弱骑兵，林地提高弓兵，城池额外提高防守方战力。城市详情面板会显示当前地形。

## 天气系统逻辑

全局天气保存在 `currentWeather`，包括晴、雨、雾、雪。结束回合时随机天气并写入日志。雨天削弱火攻加成，雾天增强伏兵，雪天降低骑兵战力。顶部栏显示当前天气。

## 武将系统逻辑

武将数据定义在 `src/data/generals.ts`，包含至少 80 名武将。武将有五维属性、忠诚、等级、经验、技能、状态、登场年月和所在城市。开局 active 武将会被放入对应城市的 `generals` 数组；wild 武将可搜索；locked 武将未到年月前不可获得。

V10.2 新增 `src/data/characterCanonProfiles.ts` 作为 Character Canon Matrix。第一批核心人物包括曹操、刘备、孙权、诸葛亮、关羽、张飞、赵云、马超、黄忠、周瑜、吕布、袁绍、董卓、司马懿、贾诩、张辽、典韦、许褚、郭嘉、荀彧、陆逊、甘宁、太史慈、黄盖、庞统、法正。每个核心人物记录史实/演义/游戏化依据、历史职能、演义人格、游戏定位、五维参考、稀有度、角色标签、标志技能、视觉关键词、说话气质和人物评语。

`src/data/generalVisualProfiles.ts` 记录核心人物原创视觉方向，包括阵营色、稀有度样式、服饰方向、配件提示、色彩提示和 flavorTitle。资源不足时，非核心人物使用文字头像、阵营色、角色定位和稀有度边框，不乱用不匹配头像。

## 武将登场逻辑

`generalSystem.checkGeneralAppearances` 在结束回合时运行。若当前年月达到武将 `appearYear` / `appearMonth`，locked 武将会变为 wild，并在日志中提示其出现城市。诸葛亮、庞统、司马懿、陆逊、姜维等都按年月延后登场。

## 技能系统逻辑

技能数据定义在 `src/data/skills.ts`。战斗技能包括突击、火攻、鼓舞、伏兵、单挑、统御、坚守；V10.2 追加破军、威压、神速、咆哮、无双、鬼谋、奇佐、诱敌、反制等对味技能。君主和内政技能包括霸业、仁德、江东、门阀、暴政、屯田、理财、安民、募兵、招贤。专项技能包括水战、骑兵、护主。`battleSystem.ts` 会在战斗中读取主将技能并修正战斗力，同时把触发信息写入战报。`turnSystem.ts` 和 `citySystem.ts` 会让内政技能影响资源产出、征兵和搜索。

## 内政系统逻辑

`citySystem.performCityAction` 处理征兵、开发农业、开发商业、修筑城防、训练士兵、搜索武将、安抚民心和侦察敌情。行动要求城市属于玩家且本回合未行动。V10.4 起，`App.tsx` 会先通过 `commandSystem.spendPlayerCommand` 扣除对应政令或军令，然后执行城市逻辑。征兵消耗金钱粮草并按城市地形增加兵种；开发和修城消耗金钱；训练消耗粮草；安抚消耗金钱并提升民心；侦察显示相邻敌城兵力和城防；搜索按执行武将智力和魅力计算概率，可发现本城或相邻城市的在野武将。

## 军团编成逻辑

V10.5 的 `src/systems/armyFormationSystem.ts` 支持军团编成 2.0。出征前由 `WarCouncilModal` 创建军团编成。系统会从出发城市 active 武将中自动选择主将、军师、先锋、左翼、右翼和后军：主将偏统率/武力，军师偏智力/政治，先锋偏武力，左右翼偏统率与机动，后军偏统率和治理稳定。

每名武将带兵上限为 `500 + command * 25 + level * 50`。如果分配兵力超过统率容量，`capacityPressure` 会降低战斗效率并增加战损风险。玩家可选择均衡编成、骑兵突击、弓兵压制、稳守反击、攻城编成，也可手动微调主将、军师、先锋、左翼、右翼、后军。兵种倾向支持均衡、步兵为主、骑兵为主、弓兵为主、水军为主、攻城为主。系统会生成编成评分：军势、战机、破阵、稳定、预计损失和 S/A/B/C 评级。

## 战斗计算逻辑

`battleSystem.resolveBattle` 执行战斗结算。系统层会二次校验进攻城市和目标城市必须相邻，且进攻城市本回合未行动。进攻方优先使用战前军议生成的 `ArmyFormation`，按军团分配兵力出战；没有编成时才回退旧的约 55% 出兵逻辑。计算考虑兵力、兵种基础战力、兵种克制、目标地形、当前天气、主将武力/统率/智力、军师智力、士气、城防、技能、统率上限压力、编成评分和战术选择。

`src/systems/battleTacticsSystem.ts` 定义五阶段战术池。阶段包括布阵、试探、交锋、破阵、收束。自动模式不暂停并全部推荐；标准模式默认进行多次关键选择；深度模式开放五阶段。战术包括稳住阵脚、快速推进、鼓舞全军、骑兵试探、弓兵压制、谋士试探、保守观察、中军强攻、左翼包抄、右翼突击、全军稳守、火攻、诱敌、主将突击、军师奇策、两翼合围、稳扎推进、守军反击、追击扩大战果、保守收兵、整备入城、放弃追击。

战术成功率受支持武将属性、技能、兵种倾向、地形、天气、编成评分和当前战术风险影响。火攻受军师智力和火攻/鬼谋/奇佐影响，雨天削弱，林地/城池增强；右翼突击受右翼武将、骑兵、神速、平原影响，雪天削弱；稳住阵脚受主将统率、后军和坚守/护主/统御影响。战术会改变军势、战机、破阵、士气、敌军势和损失风险，并写入战报。

胜利则目标城市改属进攻方，参战军团武将进驻，原守将变为在野；失败则残兵回城。主将、军师和守将按胜负获得经验。战报包含防守地形、城防、军团编成、战术记录、五阶段时间线、关键因素、指挥评分、指挥评级、主将贡献、军师贡献、翼军贡献、MVP 文案和下一步建议。`BattleModal` 会先显示战术指挥台或战斗动画，结束后进入战后复盘。

## AI 行动逻辑

`aiSystem.runAiTurn` 会为每个非玩家势力计算自身政令/军令预算。AI 每次发展、征兵或出征都会消耗预算，耗尽后停止。兵力不足时优先征兵；有优势前线且军令足够时可能攻击弱城；defensive 类型偏向修城防，economic 类型偏向发展农业/商业，aggressive 类型更容易进攻，balanced 类型均衡发展。AI 出征会自动生成军团编成并按风格选择阶段战术，但不会弹出玩家战术选择界面。玩家可在设置中选择只显示 AI 重要日志或简报。

## 存档逻辑

`saveSystem.ts` 使用 localStorage 保存完整 `GameState`。玩家开始游戏、每次行动和结束回合都会保存。刷新页面会读取存档恢复。V0.1.1 起读档会校验必要字段，异常坏档会自动移除；存档写入统一标记当前版本。重新选择主公会确认后清空存档和上次主公选择。V10.5 存档版本标记为 `V10.5.0-Perfect-Game-UI-Tactical-Command-Edition`。旧存档读取后会自动补齐 `commandState`、`currentTurnCommandsUsed`、`battleControlMode`、`commandPreferences`，并将旧 `semi` 映射为 `standard`、旧 `quick` 映射为 `auto`。

## UI 游戏化逻辑

V10.5 将 `CommandPanel` 升级为游戏命令菜单。指令面板分为城市指令、军事指令、武将、势力、情报标签页，顶部显示选中城市卡，按钮显示指令消耗、资源消耗、预期收益、推荐标签和不可用原因。顶部栏显示年月、回合、天气、势力、令牌式政令/军令、已用指令、剩余可操作城市、资源和统一进度。`WarCouncilModal` 负责完整战前军议，`ArmyFormationPanel` 支持职位和兵种倾向微调，`BattleTacticsPanel` 负责阶段战术选择，`BattleReportPanel` 负责战后复盘。整体视觉继续使用暗色沙盘、青铜/暗金边框、暗红主按钮和势力色识别。

## 标准历史模式与随机模式

当前可玩剧本仍是标准 190 年开局。该模式优先保持核心人物阵营、登场时间和职能合理，例如诸葛亮 207 年后在荆襄附近作为在野/待搜索人物出现，司马懿偏后期登场，曹操核心文武集中在中原，江东人物体现水战与火攻倾向。自定义随机模式尚未实现，未来若加入随机模式，可以轻微打散人物，但标准历史模式仍以认知正确为优先。

## 胜负判断逻辑

`App.tsx` 根据玩家控制城市数判断胜负。玩家城市数等于全地图城市数时显示“统一天下”；玩家城市数为 0 时显示“势力灭亡”。顶部栏持续显示统一进度。
