# Roadmap

## v0.1 基础策略沙盒

- Keep the local single-player strategy loop stable.
- Maintain city, command, army formation, tactical battle, AI, and save compatibility systems.
- Improve documentation and contributor onboarding.

## v0.2 事件系统

- Add a lightweight event engine.
- Support turn-based historical, semi-historical, and sandbox events.
- Keep events data-driven and easy to review.

## v0.3 Mod / Scenario 脚本

- Improve scenario definitions.
- Add safer extension points for custom cities, factions, generals, routes, and event scripts.
- Document mod-friendly data formats.

## v0.4 AI 决策与战斗平衡

- Improve AI command budgeting.
- Add clearer AI personality behavior.
- Tune battle tactics, army formation scoring, and loss formulas.
- Add regression tests for battle and turn systems.

## v0.5 英文文档和国际化

- Add English documentation.
- Prepare UI strings for internationalization.
- Keep Chinese UI as the primary supported language until i18n is stable.
