# Roadmap

## Phase 1: Open-source foundation

- Clean up the project structure
- Publish a minimal playable browser prototype
- Add documentation for setup and development
- Prepare contribution guidelines
- Add basic issue templates

## Phase 2: Core gameplay systems

- Strategic map
- City ownership and resource management
- Officer system
- Army movement
- Battle resolution
- Basic AI behavior

## Phase 3: Scenario and mod support

- Scenario configuration
- Officer and city data files
- Event system
- Save/load support
- Modding documentation

## Phase 4: Quality and maintainability

- Automated checks
- Refactoring with Codex assistance
- Unit tests for core logic
- Release notes and version tracking
