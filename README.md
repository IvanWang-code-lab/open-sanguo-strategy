# Open Sanguo Strategy

Open Sanguo Strategy is an open-source browser-based strategy game framework inspired by Three Kingdoms history and classic turn-based strategy games.

The project focuses on turn-based map strategy, city management, officers, battles, AI behavior, and mod-friendly scenario design. It is designed as a lightweight, extensible foundation for developers, game designers, and history strategy enthusiasts who want to build or study browser-based strategy systems.

## Project Goals

- Build a playable browser-based Three Kingdoms strategy prototype
- Support turn-based map control, city management, officers, armies, and battles
- Provide a clean TypeScript/Vite codebase for learning and extension
- Make scenario data, officers, cities, and AI behavior easier to modify
- Use Codex-assisted development for refactoring, testing, documentation, and maintainability

## Core Features Planned

- Strategic map and city system
- Officer and faction management
- Army movement and battle resolution
- AI decision-making for non-player factions
- Event and scenario framework
- Mod-friendly configuration files
- Save/load support
- Documentation for contributors

## Tech Stack

- TypeScript
- Vite
- React
- Browser-based frontend architecture

## Project Status

This repository is in early open-source preparation. The initial goal is to publish a clean, maintainable, and contributor-friendly browser strategy game framework.
